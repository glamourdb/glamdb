# Security policy

This policy covers GlamDB code, build workflows, and release artifacts maintained
in this repository.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's
[Security page](https://github.com/glamourdb/glamdb/security) to send a private
report to the maintainers. Please keep vulnerability details out of public
issues, pull requests, and discussions until a fix and disclosure are coordinated.

Include the affected version or commit, reproduction steps or a minimal test
case, expected and observed behavior, and the possible security impact. Remove
active credentials and private production data from any example or attachment.

We aim to acknowledge new reports within seven days. Maintainers will discuss
reproduction, remediation, and a disclosure date in the private report. Confirmed
issues will be disclosed with remediation guidance through GitHub Security
Advisories when appropriate.

## Supported versions

GlamDB is in early development and has no stable releases. Report issues against
the current `main` branch. A supported-release policy will be published before
the first stable release.

Ordinary defects without security impact can be reported in
[public issues](https://github.com/glamourdb/glamdb/issues).
